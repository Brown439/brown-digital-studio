# BROWN DIGITAL STUDIO website

## Files
- `index.html` — complete responsive website (HTML, CSS and JavaScript are included in this file).

## Publish with GitHub Pages
1. In your `brown-digital-studio` GitHub repository, choose **Add file → Upload files**.
2. Extract this ZIP on your phone first, then upload `index.html` (not the ZIP).
3. Commit the upload to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.

## Custom domain
After GitHub Pages is enabled, enter `browndigitalstudio.co.ke` in the Custom domain field in Settings → Pages. Then configure the DNS records at Truehost using the values GitHub Pages displays in its documentation/settings. DNS changes can take time to propagate.
